Projects, teams and the whole workspace each have a **Docs** area for files and folders, like specs, policies and onboarding guides.

## Where to find docs

- **Project docs:** the project's **Docs** tab.
- **Team docs:** on the team page.
- **Workspace docs:** in **Settings**, under **Workspace docs**.

## Add files

Owners and admins can **Add file** (or drop files onto the area) and create a **New folder**. Supported: PDF, Word, Excel, PowerPoint, CSV, Markdown and plain text, up to **{{upload.documentMb}} MB** each.

## Work with files

- **Preview** PDFs, images, Word, spreadsheets and text in place, or **Download** them.
- Owners and admins can **Rename**, **Delete** and **move** files and folders.
- Switch between grid and list view.

## Who can do what

| | View and download | Add, rename, move, delete |
|---|---|---|
| Owner, Admin | Yes | Yes |
| Member | Yes | No |
| Guest | No | No |
