Get around quickly with the command menu, the search boxes on each page, and a few keyboard shortcuts.

## The command menu

Press **⌘K** (Ctrl+K on Windows), or click **Search or jump to…** at the top of the page. It offers quick actions:

- **Create new issue**
- **Go to** Dashboard, Inbox, My Issues, Projects, Teams, Roadmap or Settings

Type to filter the list, then click the one you want. Press **Esc** to close it.

## Finding a specific issue, project or person

Each page has its own search box:

- **Issues:** search by title or id on All issues or My issues.
- **Projects, teams, departments, cycles and members:** search at the top of each list.
- **Inbox and Activity:** search your notifications or recent changes.
- **Help:** search all help articles.

## Keyboard shortcuts

| Shortcut | What it does |
|---|---|
| ⌘K / Ctrl+K | Open the command menu |
| ⌘Enter / Ctrl+Enter | Create the issue (on the Create Issue page) |
| Enter | Add a subtask while typing one |
| Esc | Close a dialog, the command menu or the AI Assistance bubble. On Create Issue, it stops a running AI generation |
