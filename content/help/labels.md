Labels group issues across projects and teams, for example `frontend`, `customer` or `urgent-fix`.

## Add a label to an issue

1. On the issue, or on the Create Issue page, open **Labels**.
2. Search for the label and pick it.

Members, admins and owners can add and remove labels on issues.

## Create, rename or delete labels

Only **owners and admins** can do this. When adding labels to an issue, an owner or admin can type a new name to create it on the spot.

## Labels on the issue

An issue's labels show on its page and in issue lists, so related work is easy to spot.
