**All issues** shows every issue you can see in the workspace. Each team also has its own **Issues** page in the sidebar, which shows only that team's work.

## Views

Switch with the buttons at the top:

- **List:** issues grouped by status. Best for scanning and bulk changes.
- **Board:** one column per status. **Drag a card** to another column to change its status.
- **Calendar:** issues placed on their due date. Use **Load more** to see further back.

## Filters and search

- **Search issues:** by title or issue id (like `ACME-12`).
- **Type:** All Types, Tasks, Bugs or Issues.
- **Department**, **Project** and **assignee** (Everyone, or one person).

Long lists load more issues as you scroll.

## Bulk actions (list view)

Tick the checkboxes next to issues, then use **Actions**:

- **Change Status:** moves every selected issue to the status you pick. Each issue's own workflow rules still apply, so some may not move.
- **Add To Cycle:** plans the selected issues into a cycle. They must all belong to the same team.
- **Remove:** deletes the selected issues. Owners and admins only, and you're asked to confirm. If some can't be deleted, you're told how many worked.
- **Clear:** unselects everything.

## Create an issue from here

Use **New Issue** at the top. See *Create an issue*.
